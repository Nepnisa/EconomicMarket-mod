# EconomicMarket - 基于浏览器的 Minecraft 经济系统模组

**版本：** v1.0.0  
**适用服务端：** Minecraft 1.20.1 Fabric  
**访问地址：** [http://localhost:5888/](http://localhost:5888/)

EconomicMarket 是一个纯服务端 Fabric 模组，为你的服务器提供一个**可通过浏览器访问的全能经济系统**。玩家无需安装任何客户端模组，只需在浏览器中打开指定网址，即可使用市场、拍卖行、股票交易、排行榜等功能，所有交易直接使用玩家背包中的绿宝石。

---

## ✨ 主要特性

- **🌐 网页操作** — 在任意浏览器中访问 `http://服务器IP:5888/` 即可使用，无需客户端模组。
- **💰 真实绿宝石交易** — 所有买卖、拍卖、股票交易均直接扣除或给予玩家背包中的绿宝石，不依赖虚拟钱包。
- **🛒 市场** — 从网页直接查看背包物品，一键上架；浏览其他玩家的商品并购买。
- **🔨 拍卖行** — 支持设定起拍价、加价幅度和持续时间。提供“点天灯”自动出价功能（自动加价直至获胜）。
- **📈 股票市场** — 包含 30 支中文股票（如 NE交通、微软方块等），股价每分钟随机波动，可买入卖出。
- **🏆 排行榜** — 实时展示当前在线玩家的绿宝石数量排名。
- **🔐 在线验证** — 玩家必须在线才能登录网页面板，确保账户安全。
- **⚡ 零外部依赖** — 使用 Java 内置的 `HttpServer`，无需安装额外的库或服务。
- **🎮 局域网/单人支持** — 可直接安装在客户端，对局域网开放后即可使用网页市场。

---

## 📦 安装要求

- **Minecraft 1.20.1**，需使用 **Fabric Loader** 0.14.22 或更高版本。
- **[Fabric API](https://modrinth.com/mod/fabric-api)**，需使用**Fabeic API 0.88.1** 或更高版本（服务端或客户端 `mods` 文件夹必须包含）。
- 本模组**仅支持 1.20.1**，如需用于其他版本需自行修改源码。

---

## 🚀 安装方法

### 用于专用服务器
1. 从 [Releases](https://github.com/Nepnisa/EconomicMarket-mod/releases) 下载 `EconomicMarket-v1.0.0.jar`。
2. 将 jar 放入服务器 `mods` 文件夹。
3. 确保同一文件夹内已安装 **Fabric API**。
4. 启动服务器。
5. 在浏览器中访问 `http://服务器IP:5888/`，输入游戏内在线用户名登录。

### 用于单人存档或局域网联机
1. 将模组 jar 放入**客户端** `.minecraft/mods/` 文件夹。
2. 启动游戏，进入单人存档。
3. 按 `Esc` → **对局域网开放**（可允许作弊）。
4. 在浏览器中访问 `http://localhost:5888/`，输入用户名登录。
5. 局域网内其他玩家可通过主机 IP 地址访问，例如 `http://192.168.1.5:5888/`。

> ⚠️ 客户端使用时，必须将模组放入客户端的 `mods` 文件夹，**不需单独运行服务端**。

## 🛠️ 自行构建

1. 克隆本仓库。
2. 运行 `./gradlew build`（需要 JDK 17）。
3. 构建产物位于 `build/libs/EconomicMarket-v1.0.0.jar`。

---

## ⚙️ 配置与自定义

- 所有数据（市场、拍卖、股票持仓）保存在 `config/economicmarket/` 文件夹下。
- 默认 HTTP 端口为 `5888`，可在 `MarketMod.java` 中修改。
- 网页界面支持自定义：将修改后的 HTML/CSS/JS 放入 `config/economicmarket-web/`，模组会优先加载它们。

---
